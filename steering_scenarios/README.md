# steering_scenarios

Groundwork for the team's main direction (2026-10-14): can we steer a model towards myopic or long-term
behaviour in realistic planning/advice tasks, above baseline noise?

## Contents

- `literature_brief/index.html` — literature brief: how to build realistic scenarios (sources, scenario cards with
  an option ladder), what to measure and what not to, which baselines to beat (random directions, prompting),
  confounds (risk/prudence, verbosity, option order, phrasing, degradation), and the "are you sure?" flip test.
  Open the file in a browser. Citations tagged `secondary` / `unverified` should be checked before reuse.
