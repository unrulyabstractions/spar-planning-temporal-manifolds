Reading (all three parts needed):
1. Magnitude organizes the path: canonical-trained ridge transfers to rewrites at R² 0.78–0.89.
2. A unit rewrite moves a sample along the path by < 1 grid step (|along| ≤ 0.74), and its orthogonal
   displacement (1.2–4.8 steps per pair) is below the same-bin single-sample floor (4.0–5.0). The
   centroid-level unit offset seen in dataset A (1.5–2.4 steps) is therefore small relative to
   per-sample spread and mostly orthogonal to the path.
3. Behavior nevertheless shifts with unit ("decades" −0.11, "centuries" −0.07: treated as longer
   than "N years"), and the along-path shift does not predict it per unit (decades along ≈ 0;
   hours along −0.7 "shorter" but behavior −0.05 "longer"). The linear magnitude readout misreads
   "decades"/"centuries" as shorter (resid −0.3 to −0.9 decades) while the model acts as if longer.
   → the path coordinate is necessary but not sufficient for behavior; the unit effect on behavior
   rides on a direction off the path (or a later computation). Pair-level Spearman(Δalong, Δp_short)
   has the expected sign (negative) but is weak prompt-side (−0.12 to −0.16) and moderate only at
   the post-decision response token (−0.33).

## Appended: interactive 3-D viewer (Alan's request)

`scripts/plot3d.py RUN OUT --cells L:POS,... [--basis centroid|sample]` writes one standalone Plotly HTML per
cell: all valid samples in (PC1, PC2, PC3), colored by log horizon (null gray) with hover details, the
bin-centroid path as a labeled line, and a button to recolor points by choice. Default basis = PCA of the
bin centroids (same basis as `geometry_path.py`'s 2-D path figures); `--basis sample` gives the sample-PCA
basis of `analyze.py`'s cell scatters. Axis titles carry each component's explained-variance ratio.
`plotly.min.js` is written once per figures directory (4.8 MB) and shared by the ~390 KB HTML files.
Generated: extended run L22 R0 / L37 T3 / L29 R0; canonical v2 run same cells + L22 R0 in the sample basis.
Added dependency: plotly 7.1.0.
