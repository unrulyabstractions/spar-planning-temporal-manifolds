## Step 1: fit.py's computation moved into `steer/fitting.py` (no change in behaviour)

### Summary

- `fit.py:main()` held the whole fit, so a refit (needed for Augusto's label-shuffled null N4 and for held-out-horizon
  refits) could only run as a command. The computation now lives in `steer.fitting.fit(X, recs, chosen, FitSettings)`,
  together with `select`, `cross_validated_t` and `log10_days`.
- `fit.py` keeps argument parsing, loading, writing and logging.
- Its command line is unchanged, and so is the `settings` block it records.
- The only interface addition is `main(argv=None, fits_root=HERE / "fits")`, so tests can run it into a temporary
  directory.

### Files

- New:
  - `steer/fitting.py`;
  - `tools/compare_fits.py`;
  - `tests/fixtures.py`, a synthetic extract.py output over the real t0_s0 bank;
  - `tests/test_fit.py`.
- Changed:
  - `fit.py`;
  - `pyproject.toml`: pytest `pythonpath = ["."]`, so tests can import the scripts;
  - `steer/__init__.py` and `README.md`: the code maps and the test list.

### Decisions

- **The refactor is verified by exact comparison with the old code's outputs, not by tests written afterwards.** Before
  editing, the old `fit.py` (at afa170a) was run on real activations with four settings combinations, and the outputs
  were saved. The new code reran the same four. Tolerance-based golden files were rejected: SVD signs and last bits
  can differ across BLAS builds, so a committed golden test would be flaky on teammates' machines. Exact comparison at
  the moment of the refactor is what shows "no behaviour change".
- **`tools/compare_fits.py` is committed** so the comparison can be reproduced, and reused for later "should be
  identical" checks.
  - Arrays are compared with `np.array_equal`, dtype and shape.
  - JSON files are compared after dropping only `created_utc` and `code_commit`.
  - Everything else is compared byte for byte.
