## Summary

Alan asked for one pull request bringing the prompt-bank and steering-vector work into `main`, so the team can use
it without switching branches. `steering-vectors` already contains `prompt-bank` (it was branched from it), so one PR
from `steering-vectors` covers both.

`main` had moved 31 commits since the branch point (92bac57), mostly Jared's pipeline reorganisation under
`jared/pipeline/` (#9, #10). A test merge (`git merge-tree --write-tree origin/main origin/steering-vectors`) showed


Both sides had created a root `.gitignore` independently:

  shell rc files, `.idea`, `.vscode`);

Resolution: keep both, with main's list first and then the `.env` block unchanged. No other path overlaps: neither
`prompt_bank/` nor `steering/` exists on `main`, and the branch touches no other root file.

## Decisions

- **Merged `main` into the branch rather than rebasing onto it.** The branch is already pushed, and a rebase would
  rewrite six published commits for no gain. The merge commit records the one conflict resolution in a single
  place.
- **`steering/` is kept separate from `jared/pipeline/s2_steering` and `spar_horizon` for now.** Unifying them is a
  team decision, not part of this merge. Overlap noted from `jared/pipeline/s2_steering/DECISIONS.md` on `main`:
  - Layer convention (its line 40): the same as `steering/`. `layer` = hidden_states index; an edit at L hooks
    decoder layer L-1; only 1..n_layers-1 are allowed.
  - Mean difference (its line 73): "Long half minus short half at the median log horizon ... Steers backwards
    because the short half is all `none`". `steering/` follows the report (A.3) instead: H/D >= 4 against
    H/D <= 1/4. Whether "none" belongs in the classes at all is still the open question recorded in
    `steering/README.md`, choice 1.
